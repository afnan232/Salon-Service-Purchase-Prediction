# Salon Service Purchase Prediction

A small educational machine-learning project that predicts whether a salon customer purchases a service (`Purchased`).

## Project contents

- `Salon_Service_Purchase_Prediction.ipynb` — the complete notebook, organized into three parts:
  1. Main project: initial classification workflow
  2. Lab 2: feature engineering and preprocessing pipeline
  3. Lab 3: model comparison, hyperparameter tuning, threshold evaluation, and feature importance

## Requirements

- Python 3
- pandas
- scikit-learn
- Jupyter Notebook or JupyterLab

Install dependencies:

```bash
pip install pandas scikit-learn jupyter
```

## Run

Open the notebook in Jupyter and choose **Run All**.

## Dataset note

The notebook uses an illustrative dataset containing only 8 records. Results demonstrate the machine-learning workflow and are not suitable for real-world business decisions.
